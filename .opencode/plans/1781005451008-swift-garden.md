# Plan: Change Chat Creation Flow

## Goal
Redesign the chat creation dialog to have a clear 2-step flow:
1. Choose chat type (Personal or Group)
2. Enter chat name and select participants

## Current State
- Single dialog with optional name input and user list
- Chat type auto-determined by number of selected users (1 = personal, >1 = group)
- No explicit type selection step

## New Flow
1. User clicks "+" button → Dialog opens with chat type selection
2. User selects type:
   - **Personal**: Can select exactly 1 user
   - **Group**: Can select multiple users or none
3. After selecting type, dialog shows:
   - Chat name input at the top (required for groups, optional for personal)
   - User list below with checkboxes
   - Footer with Cancel/Create buttons
