# Plan: Change Chat List Icons

## Goal
Update chat list icons to show:
- **Personal chats**: First letter of the interlocutor's name
- **Group chats**: First letter of the chat name

## Current State
- Personal chats use `<UserAvatar>` which shows **2 letters** (first 2 characters of name)
- Group chats show a hardcoded `#` character in a blue circle

## Implementation

### Step 1: Modify UserAvatar component
**File**: `src/frontend/src/components/UserAvatar.tsx`

Add a `maxInitials` prop to control how many characters are displayed:
```typescript
interface UserAvatarProps {
  user?: Pick<User, 'id' | 'name' | 'uniq_name' | 'avatar_url'> | null
  size?: number
  showOnline?: boolean
  maxInitials?: number  // NEW: default 2
}
```

Update the `initials` function to use `maxInitials`:
```typescript
function initials(u: UserAvatarProps['user'], max: number = 2): string {
  if (!u) return '?'
  const src = u.name?.trim() || u.uniq_name || '?'
  return src.slice(0, max).toUpperCase()
}
```
